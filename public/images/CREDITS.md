### Licence notes

- **CC BY 2.0 / CC BY-SA 4.0** — attribution required (this file is the
  attribution). CC BY-SA additionally requires that any adapted version of the
  photograph is shared under the same licence; the site only resizes and
  re-encodes them, and the originals are linked above.
- **CC0 1.0** — public-domain dedication, no attribution required (credited
  above anyway).

## Local processing

All stock files were resized and re-encoded locally (WebP, longest edge
≤ 1600 px, quality tuned for the web) for the `next/image` optimizer. No
photograph is embedded in the page directly from a third-party host.
